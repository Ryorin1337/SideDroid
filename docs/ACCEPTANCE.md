# 验收清单

需要：这台电脑、一台开启 USB 调试的 Android 手机。产物在 `out\`。

如果某步失败，把 `%LOCALAPPDATA%\SideDroid\host.log` 和手机的 `adb logcat -s SideDroid` 输出发给我。

## 1. 安装（最关键）

这一步决定“不开测试模式也能用”是否成立。**测试前确认 Secure Boot 开着、测试模式关着。**

- [ ] 运行 `SideDroid-0.0.1.msi`，安装完成后控制台自动打开
- [ ] 控制台显示“还差一步”，点“安装驱动”
- [ ] 依次确认 UAC 和 Windows 的发布者提示（发布者应为 SignPath Foundation）
- [ ] 不需要重启、不需要开启测试模式，控制台提示消失
- [ ] 检查系统没有多出一块空屏幕：Windows 显示设置里仍然只有原来的屏幕
- [ ] 托盘里有 SideDroid 图标，关掉控制台后图标还在

驱动如果装不上，把错误提示告诉我，这决定下一步的方向。

## 2. USB

```powershell
adb install -r out\SideDroid-0.0.1.apk
```

- [ ] 手机连接后，控制台显示“已检测到 USB 设备”；未授权时提示去手机上允许
- [ ] 手机上点“USB 连接”，几秒内出现画面
- [ ] Windows 显示设置里多了一块屏幕，分辨率等于手机分辨率
- [ ] 把窗口拖到这块屏幕上，手机能看到，鼠标光标也能看到
- [ ] 手机上观察拖动的跟手程度，主观延迟可以接受
- [ ] 控制台显示设备名、USB、编码器和实时数字

## 3. 副屏和镜像

**手机和电脑要一起升到 0.0.1，版本不一致时无法连接。**

- [ ] 默认是副屏：手机显示的是独立的桌面，不是主屏的复制，Windows 显示设置里是“扩展这些显示器”
- [ ] 连接前后主屏分辨率和刷新率都不变
- [ ] 把模式切到“镜像”：手机显示主屏内容，比例不符时有黑边；主屏不闪、分辨率不变
- [ ] 镜像下触控能准确操作主屏
- [ ] 切回“副屏”后恢复独立桌面
- [ ] 控制台、托盘菜单、手机工具条都能切换，并且三处显示一致
- [ ] 断开后主屏回到连接前的分辨率、刷新率和布局

## 3.1 分辨率和缩放

- [ ] 分辨率是下拉列表：自适应手机（推荐）、自适应电脑、常用分辨率，默认选中自适应手机
- [ ] 选自适应电脑后，副屏等于电脑主屏的尺寸，手机上按比例显示，有黑边时触控仍然准确
- [ ] 缩放是下拉列表，默认选中标有“推荐”的一项，手机上的文字大小合适
- [ ] 改变缩放后，Windows 显示设置里虚拟屏的缩放同步变化，主屏的缩放不变

## 3.2 不再无限开窗口

- [ ] 控制台开着时，连续多次点托盘的“打开控制台”，始终只有一个窗口，并且会回到最前面
- [ ] 重复双击开始菜单的 SideDroid，同样只有一个窗口
- [ ] 任务栏里没有多出一堆 SideDroid
- [ ] 控制台开着时点托盘的“退出”，能正常退出

## 3.3 托盘菜单

- [ ] 右键托盘图标能看到连接状态、分辨率、帧率、码率和延迟
- [ ] 模式、分辨率、刷新率、画质子菜单都能切换，当前选项有勾
- [ ] “允许无线连接”“添加设备”“断开连接”“打开控制台”“退出”都有效
- [ ] 点菜单外面时菜单会关闭
- [ ] 鼠标悬停在图标上能看到状态提示
- [ ] 连接时选择“退出”，电脑的显示布局能恢复

## 3.4 触控

- [ ] 单指点击能点中按钮，位置准确（重点检查四个角）
- [ ] 单指拖动能滚动网页或拖动窗口
- [ ] 双指缩放在支持的应用里有效（如 Edge 或照片）
- [ ] 手指抬起后没有卡住，电脑的鼠标正常

## 4. 显示设置

- [ ] 控制台把分辨率切到 1080p，屏幕切换后画面正常，触控位置仍然准确
- [ ] 切回“自适应”，恢复手机分辨率
- [ ] 切换刷新率 60 / 90 / 120（手机支持的），Windows 显示设置里同步变化
- [ ] 手机底部的工具条（点右边缘的小把手打开）也能切换
- [ ] 旋转手机，Windows 副屏跟着横竖切换，触控仍然准确

## 5. Wi-Fi

先拔掉 USB，手机和电脑在同一网络。

- [ ] 手机首页列出这台电脑，显示“未配对”
- [ ] 控制台点“添加设备”，显示配对码和倒计时
- [ ] 手机上点电脑并输入配对码，连接成功；控制台的设备列表出现这台手机
- [ ] 输错配对码时提示不正确，不会连接
- [ ] 断开后重连，不需要配对码
- [ ] 在控制台移除设备后，手机再连接会要求重新配对
- [ ] 关闭控制台里的“无线连接”后，手机无法通过 Wi-Fi 连接

## 6. 自适应码率

- [ ] 在 Wi-Fi 下播放视频，控制台的码率会随内容和网络变化
- [ ] 走到信号差的地方或开大流量下载，画面变糊但不长时间卡死；控制台可能提示“网络受限”
- [ ] 回到信号好的地方，几十秒内画质恢复

## 6.1 平板和不同窗口大小

- [ ] 平板或折叠屏展开时，首页左右分栏；手机竖屏是单栏，横屏是分栏
- [ ] 分屏或旋转后布局马上跟着变，内容没有被截断
- [ ] 串流时打开设置：宽窗口在右侧，窄窗口在工具条上方，都不会被工具条盖住

## 7. 断开

- [ ] 手机上点“断开”或按返回键，5 秒左右副屏从 Windows 消失，窗口回到主屏
- [ ] 直接拔线或关掉手机应用，同样能恢复
- [ ] 重新连接正常

## 7.1 关于

- [ ] 控制台标题栏和手机首页都有关于按钮，显示版本 0.0.1、作者 Ryorin、MIT 许可证和仓库地址
- [ ] 点“打开 GitHub”能打开浏览器（仓库创建之前会是 404）

## 8. 卸载

- [ ] 在 Windows 设置里卸载 SideDroid
- [ ] 设备管理器里没有 Virtual Display Driver
- [ ] `C:\VirtualDisplayDriver` 和防火墙规则“SideDroid Host”都已删除
- [ ] 开机启动项里没有 SideDroid

如果你在安装 SideDroid 之前就装过 VDD，卸载后它应该原样保留。

## 9. 其他设备（如果有）

- [ ] 一台 Android 8~10 的设备：能连接、能解码，延迟可能更高
- [ ] 一台 Intel 或 AMD 显卡的电脑：确认 Media Foundation 编码可用
